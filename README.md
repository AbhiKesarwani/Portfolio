## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/AbhiKesarwani/Portfolio.git
cd Portfolio
npm install
```

### Development

```bash
npm run dev
```

The development server will start using Vite.

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
